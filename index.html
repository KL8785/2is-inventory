☁ 設定 Google Drive 同步

完成一次性設定後，即可將所有庫存資料雙向同步到 Google Drive，任何電腦開啟此檔案都能存取最新資料。

1
前往 Google Cloud Console，建立新專案（如 2is-inventory）
2
在左側選單 API 和服務 → 程式庫，搜尋並啟用 Google Drive API
3
前往 API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID，應用程式類型選 網路應用程式
4
在「已授權的 JavaScript 來源」新增 null（本機 HTML 檔案用）
5
複製用戶端 ID（格式如 123456.apps.googleusercontent.com）貼到下方
💡 同步資料儲存為 2is_inventory_data.json，預設存到你指定的資料夾（如 Work/庫存系統；未填則放 Drive 根目錄），可隨時查看或分享給他人。
📁 資料夾 ID＝在 Drive 開啟目標資料夾，網址 /folders/ 後面那段。留空則存到 Drive 根目錄。
